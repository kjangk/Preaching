# 주해설교

## 목적

성경의 모든 절을 본문 순서대로 읽고 해석하며 설명하는 설교문을 작성한다. 설교자마다 생기는 개인 편차를 줄이고, 성경에서 벗어난 이야기에 시간을 지나치게 사용하는 위험을 줄인다. 말씀이 풀어질 때 역사하시는 하나님의 능력을 신뢰한다.

## 작성 원칙

1. 요청한 범위의 모든 절을 생략 없이 순서대로 다룬다.
2. 기본 성경 역본은 개역개정으로 한다. 사용자 제공 본문을 정확하게 보존하여 사용한다.
3. 형식은 **한 절의 성경 본문 → 그 절의 해설 → 다음 절의 성경 본문 → 그 절의 해설**로 한다.
4. 해설은 앞뒤 문맥, 구절의 의미, 필요한 배경과 주석을 중심으로 한다. 원어는 본문을 이해하는 데 도움이 될 때만 짧게 설명한다.
5. 각 절의 해설 분량은 같게 맞추지 않는다. 핵심 구절에는 더 배분하고, 질문이나 연결 구절은 짧게 설명한다.
6. 본문에 없는 의미를 만들어 넣거나 근거가 불확실한 해석을 확정적으로 말하지 않는다. 해석이 나뉘는 부분은 핵심 쟁점만 짧게 밝힌다.
7. 적용은 설명한 본문의 의미에서 직접 나오도록 한다. 모든 절에 억지로 적용을 붙이지 않는다.
8. 본문의 흐름을 임의의 세 대지로 재배열하지 않는다. 긴 예화나 별도의 주제 강연을 삽입하지 않는다.
9. 설교자가 자연스럽게 읽고 전할 수 있는 문장으로 작성한다.
